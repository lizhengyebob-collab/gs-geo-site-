# GS GEO AI 可见度测试操作指南

> 版本：v1.0 · 最后更新：2026-05-30  
> 负责人：市场/增长团队  
> 配套文件：`ai-visibility-test-template.csv`、`first-baseline-questions.md`

---

## 一、测试目标

本测试旨在追踪 **GS GEO 品牌在主流 AI 搜索平台中的可见度表现**，包括：

- **出现率**：在多少个平台、多少类问题中被提及
- **引用质量**：描述是否准确，是否包含官网链接
- **排名位置**：与竞品相比在 AI 回答中的排名
- **趋势变化**：随时间推移出现率是否提升

测试结果直接用于：指导 GEO 内容优化策略、评估已发布内容的引用效果、追踪竞品在 AI 搜索中的动态。

## 三、每个平台测试步骤

### 通用准备

```
测试前清除浏览器缓存或使用无痕/隐私模式
使用普通用户账号，不要使用管理员或开发者账号
每次测试间隔至少 30 秒，避免连续提问影响上下文
将每个回答截图保存，命名格式：平台名_问题类型_日期.png
```

---

### Perplexity 测试步骤

```
1. 访问 perplexity.ai，选择「Focus: All」模式（不要限定来源）
2. 直接在输入框粘贴测试问题，回车发送
3. 等待回答生成完毕（通常 5-15 秒）
4. 重点观察：
   ✓ 回答文字中是否出现「GS GEO」
   ✓ 右侧引用来源列表中是否出现 geo.goushaoai.com
   ✓ GS GEO 在推荐列表中排第几位
5. 截图保存完整回答（含引用来源）
6. 填写测试记录表
```

**Perplexity 特别说明**：Perplexity 会直接展示引用链接，是最容易核实来源的平台。如果 geo.goushaoai.com 出现在引用列表，说明 Perplexity 已能抓取我们的网站内容。

---

### ChatGPT 测试步骤

```
1. 访问 chat.openai.com，新建对话
2. 确认使用 GPT-4o（默认最新版本）
3. 直接粘贴测试问题，发送
4. 如果 ChatGPT 没有 Search 功能显示，正常记录纯文字回答
5. 如果出现 Search 图标（实时搜索），特别记录引用来源
6. 重点观察：
   ✓ 回答中是否提到「GS GEO」品牌名
   ✓ 是否提到「geo.goushaoai.com」
   ✓ 推荐了哪些竞品（记录在备注）
7. 截图保存，填写记录表
```

**ChatGPT 特别说明**：ChatGPT 的训练数据有时效性滞后，新品牌在训练数据中不存在时，主要通过 ChatGPT Search（Bing 索引）被引用。关注是否出现搜索图标是判断引用来源的关键。

---

### 豆包 测试步骤

```
1. 访问 doubao.com 或打开豆包 App，新建对话
2. 选择默认对话模式（不要选「联网搜索」关闭状态）
3. 建议开启联网搜索功能（如有开关）
4. 粘贴测试问题，发送
5. 重点观察：
   ✓ 是否提到「GS GEO」
   ✓ 描述中的定位是否准确（与实际服务匹配）
   ✓ 与竞品相比出现的先后顺序
6. 截图，填写记录
```

**豆包特别说明**：豆包偏向国内知乎、微信公众号、头条等平台的内容。如果测试中长期未出现，优先在知乎增加 GS GEO 相关内容的发布频次。

---

### DeepSeek 测试步骤

```
1. 访问 chat.deepseek.com，新建对话
2. 选择「DeepSeek-V3」或默认最新模型
3. 粘贴测试问题，发送
4. 等待完整回答（DeepSeek 响应速度较快）
5. 重点观察：
   ✓ 是否提到「GS GEO」
   ✓ 回答逻辑是否将 GS GEO 定位为专业服务商
   ✓ 是否出现错误的品牌描述
6. 截图，填写记录
```

**DeepSeek 特别说明**：DeepSeek 对有明确数据支撑、逻辑结构清晰的中文内容引用率更高。如果测试结果不理想，重点优化面向 DeepSeek 的内容格式（加数据、加列表结构）。

---

### Claude 测试步骤

```
1. 访问 claude.ai，新建对话
2. 选择 Claude 3.5 Sonnet 或最新版本
3. 粘贴测试问题，发送
4. 重点观察：
   ✓ 是否提到「GS GEO」
   ✓ 描述风格是否偏向专业/学术（Claude 引用标准较高）
   ✓ Claude 对 GS GEO 的定性描述是否准确
5. 截图，填写记录
```

**Claude 特别说明**：Claude 对「营销感」强的内容引用率极低，偏好引用有研究背景、有数据来源的专业内容。测试结果长期不理想，说明需要发布更多方法论类、研究型内容。

### Kimi 测试步骤

```
1. 访问 kimi.ai（Moonshot AI），新建对话
2. 开启联网搜索（右下角联网按钮）
3. 粘贴测试问题，发送
4. 重点观察：
   ✓ 是否提到「GS GEO」
   ✓ 是否展示搜索来源链接
   ✓ 与其他平台对比，描述是否有差异
5. 截图，填写记录
```

## 四、字段填写说明

| 字段 | 类型 | 填写规范 | 示例 |
|------|------|---------|------|
| **测试日期** | 日期 | YYYY-MM-DD | 2026-06-01 |
| **平台** | 固定值 | ChatGPT / Claude / Perplexity / 豆包 / DeepSeek / Kimi | ChatGPT |
| **问题类型** | 固定值 | 品牌发现类 / 服务推荐类 / 术语解释类 / 竞品替代类 / 采购决策类 | 品牌发现类 |
| **测试问题** | 文本 | 照抄，不要修改 | 国内有哪些专门做 GEO... |
| **是否提到 GS GEO** | Y/N/部分 | Y=明确提到品牌名；部分=提到网站或服务但未说品牌名；N=完全未提及 | N |
| **是否引用网址** | Y/N | Y=出现完整域名或可点击链接；N=未出现 | N |
| **排名/位置** | 文本 | 首位 / 第2 / 第3 / 末尾 / 未提及 | 未提及 |
| **回答摘要** | 文本 | 复制 AI 回答中与 GS GEO 相关的原文（100字内），或记录推荐了哪些竞品 | 推荐了A公司和B公司，未提及GS GEO |
| **需要优化的内容** | 文本 | 根据回答分析：描述不准确/未被提及/排名靠后/竞品描述更好，记录具体改进方向 | 需在知乎发布品牌发现类内容 |
| **截图链接** | URL/路径 | 截图文件路径或云存储链接 | screenshots/chatgpt_brand_2026-06-01.png |
| **备注** | 文本 | 其他观察，如竞品名称、回答异常等 | 竞品X被首位推荐 |

## 五、评分标准

### 单题评分（每题 0-3 分）

| 得分 | 条件 |
|------|------|
| **3 分** | 明确提到 GS GEO + 排名前 2 + 描述准确 |
| **2 分** | 提到 GS GEO 但排名靠后，或提到但描述不准确 |
| **1 分** | 仅提到网站/部分关键词，未明确提到品牌名 |
| **0 分** | 完全未提及 |

### 平台总分（5 题，满分 15 分）

| 分段 | 状态 | 建议行动 |
|------|------|---------|
| **12-15 分** | ✅ 优秀 | 维护现有内容节奏，关注描述准确性 |
| **8-11 分** | 🟢 良好 | 针对低分题型补充对应内容资产 |
| **4-7 分** | 🟡 建设中 | 重点平台专项优化，2 周内发布针对性内容 |
| **0-3 分** | 🔴 紧急 | 该平台几乎隐身，需要立即开展平台针对性内容策略 |

### 全平台出现率（每两周统计）

```
出现率 = 提到 GS GEO 的题目数 / 总测试题目数（30题）× 100%

基线期（第1次测试）：记录出现率，作为后续对比基准
第2次测试：对比变化，分析趋势
持续跟踪：出现率 ±20% 以上需要制定专项优化计划
```

## 六、每两周复测流程

### 测试日历

```
推荐执行节奏：每两周周一上午 9:00-12:00
耗时估算：每平台约 30 分钟（5题 × 6分钟/题）
总计约 3 小时（6个平台）
```

### 复测 SOP（标准操作程序）

```
Step 1 — 准备（测试前一天，10分钟）
  □ 复制上一期 CSV，重命名为 ai-visibility-YYYY-MM-DD.csv
  □ 清空结果列（保留问题列）
  □ 创建截图文件夹：screenshots/YYYY-MM-DD/

Step 2 — 执行测试（当天，3小时）
  □ 按平台优先级顺序：Perplexity → ChatGPT → 豆包 → DeepSeek → Claude → Kimi
  □ 每题使用新的对话窗口（避免上下文干扰）
  □ 每题截图保存
  □ 实时填写 CSV

Step 3 — 整理分析（测试后，30分钟）
  □ 统计各平台得分和全平台出现率
  □ 与上期数据对比，标注变化
  □ 记录本期出现的新竞品名称
  □ 输出 3 条下一步优化建议

Step 4 — 归档（5分钟）
  □ 将 CSV 和截图文件夹存入云盘
  □ 更新追踪看板（飞书/Notion/Excel）
```

## 七、如何根据测试结果调整 GEO 内容策略

### 决策矩阵

| 测试发现 | 根因分析 | 对应行动 |
|---------|---------|---------|
| **某平台完全未提及** | 该平台的爬虫无法访问或内容不在其索引来源 | 确认 robots.txt 权限；在该平台偏好的来源平台发布内容 |
| **出现但描述不准确** | AI 系统读取了错误的第三方来源，或 llms.txt 描述不清晰 | 更新 llms.txt；在知乎发布权威定义内容；检查第三方来源描述 |
| **排名靠后（第3+）** | 竞品引用信号更强，或内容权威度不足 | 增加第三方引用来源；发布带数据的深度内容；提高发布频率 |
| **品牌发现类未出现** | 品牌实体在 AI 系统中认知不足 | 在知乎发布「GS GEO 是什么」类内容；完善 Organization Schema |
| **服务推荐类未出现** | 服务描述不够具体，AI 无法将品牌与具体服务场景匹配 | 增加服务场景化描述；发布行业 Case Study；完善 Service Schema |
| **术语解释类出现但服务类未出现** | 品牌被认知为「知识输出者」而非「服务提供商」 | 在内容中增加「GS GEO 提供 XX 服务」的明确表述；强化采购场景内容 |
| **竞品替代类竞品优势明显** | 竞品的权威来源更多，被 AI 优先引用 | 分析竞品的第三方引用来源，在相同平台建立 GS GEO 内容 |
| **采购决策类未出现** | 缺乏帮助买家做决策的结构化内容 | 发布「如何选择 GEO 服务商」类采购指南；加入评估标准对比 |

### 内容优化优先级决策树

```
出现率 < 20%？
  → 是 → 立即：技术检查（llms.txt、Schema、robots.txt）
           本周：在知乎发布 2 篇品牌发现类内容
           两周内：覆盖所有 5 种问题类型

出现但描述不准确？
  → 是 → 更新 llms.txt（本周）
           发布「GS GEO 是什么」权威定义文章
           联系描述错误的第三方来源更正信息

出现率 20-60%？
  → 找出未出现的平台 → 针对该平台引用偏好调整内容格式
  → 找出未出现的问题类型 → 针对该类型发布专项内容

出现率 > 60%？
  → 聚焦：提升排名位置（从第3变为首位）
  → 聚焦：引用 geo.goushaoai.com 的比率
  → 监控：竞品动态变化
```

## 八、附录

### 快速参考：各平台偏好内容类型

| 平台 | 偏好引用的内容类型 | 不易被引用的内容类型 |
|------|-----------------|------------------|
| ChatGPT | 知乎深度回答、行业媒体文章、有作者署名的专业内容 | 纯营销软文、没有来源的主观判断 |
| Claude | 学术风格文章、有明确数据来源的研究内容、方法论框架 | 广告文体、夸张性表达、无引用的内容 |
| Perplexity | 任何公开可抓取的新鲜内容、有来源链接的统计数据 | 无法访问的内容（权限问题）、过时内容 |
| 豆包 | 知乎、微信公众号、头条号等国内权威平台内容 | 海外平台独有内容、描述与国内平台不一致的信息 |
| DeepSeek | 数据驱动、逻辑严密、有步骤说明的中文内容 | 模糊表达、缺乏结构的文章 |
| Kimi | 综合多来源信息、联网搜索结果 | 无法被联网爬取的内容 |

### 竞品追踪说明

每次测试时，在「备注」列记录 AI 推荐了哪些竞品。建议维护一份竞品出现频率表：

```
竞品名称 | 首次出现日期 | 出现平台 | 出现问题类型 | 频次趋势
```

竞品出现频率的变化可以帮助判断：哪些竞品正在加强 GEO 布局，以及哪些方向的竞争最激烈。
